## Дополнения для ЛР2

- `open_hash.go`: обобщённая таблица ключ–значение, линейное пробирование
  и двойное хеширование, очистка меток и расширение.
- `set.go`: множество для заданий 2 и 3 поверх собственной таблицы.
- `lru.go`: кэш поверх LinkedList/Node из личной ЛР1 и новой хеш-таблицы.
  Доступ по указателю позволяет перемещать узел за O(1) без поиска в списке.
- `tasks/taskN.go`: решения под номер 5, включая задание 6 и файловое множество.
- `tasks/task5.go`: загрузка повреждённого BST непосредственно в Tree/TreeNode
  личной ЛР1; восстановление значений без перестановки ссылок. Insert по уровням
  из Complete Binary Tree для этой загрузки не вызывается.
- `main.go`: меню, отдельный запуск заданий, обработка ошибок.
- Тесты, примеры, Makefile, пояснения и эксперимент.

Исходная папка личной ЛР1 не изменялась. Исполняемые и объектные файлы из
ЛР1 и чужого примера в выдачу не включены. Проект собирается на своей системе.
