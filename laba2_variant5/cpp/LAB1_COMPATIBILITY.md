# C++ и личная ЛР1


| Модуль ЛР1 | Использование C++ в ЛР2 |
|---|---|
| stack.cpp, one_linked_list.cpp | Стек обхода зависимостей и иерархий |
| array.cpp | Словарь задания 4 |
| linked_list.cpp, node.h | Порядок использования ключей LRU |
| tree.h | Узлы и корень повреждённого BST |
| queue.cpp, tree.cpp и остальные заголовки | Сохранены в составе базовых структур |

Изменён только перенесённый array.cpp. Максимальная ёмкость теперь определяется
доступной памятью и диапазоном size_t, а выделение и копирование временного буфера
защищены unique_ptr. Исходная личная ЛР1 не изменена.
Проверка дерева высотой 30000 выполнена без рекурсивного освобождения.

Тип TreeNode из ЛР1 содержит int. Ввод значений BST в C++ ограничен int32;
Go использует int64. Общие проверки деревьев используют значения int32.
