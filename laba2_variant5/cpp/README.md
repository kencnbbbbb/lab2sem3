# ЛР2 на C++17

Порядковый номер 5. Все задания реализованы в самостоятельном C++-проекте.

## Сборка из корня

```sh
make cpp
./laba2-cpp --task 3 < examples/task3.txt
make test-cpp
make cross-test
make experiment-cpp
```

В каталоге cpp также работают `make` и `make test`.
Нужны компилятор C++17 и Make. Для общей проверки нужны Go и Python 3.

## Реализация

- Стек ЛР1 используется для итеративного DFS в заданиях 1 и 6.2.
- Собственные HashTable и Set разрешают коллизии линейным пробированием или двойным хешированием.
- Set используется в заданиях 2, 3 и 4. Файлы множества совместимы с Go.
- Собственный массив ЛР1 хранит словарь ударений.
- Восстановление BST меняет только два значения, сохраняя связи исходных узлов.
- LRU использует двусвязный список ЛР1 и HashTable с указателями на узлы.

Типы узлов дерева сохранены из ЛР1: значения BST в C++ помещаются в int32.
История переноса структур: [LAB1_COMPATIBILITY.md](LAB1_COMPATIBILITY.md).

## Проверки

`tests/test_main.cpp` содержит 13 групп проверок с независимыми эталонами для
хеш-таблицы и LRU. `tests/verify_cli.py` проверяет примеры, случайные входы,
все обмены пар значений в тестовых BST, длинные входы и совместимость C++/Go.
Проверки ошибочных запросов убеждаются, что файл множества сохраняется.

## Эксперимент

`../laba2-cpp --task 6.1` выводит CSV из 12 строк.
Одинаковые ключи для двух методов создаются до измерения. Для случайного набора
используется SplitMix64 с состоянием 5, ёмкость 16384. Для коллидирующего набора
отбираются ключи collision_i с DJB2 mod 1024 = 0.
Заполнение — 25, 50 и 65 процентов. Для каждого набора измеряются вставка,
успешный поиск, промах и удаление. Времена — наносекунды за серию.
Серия промахов включает создание строк missing_. Средние пробы равны
счётчику проб, делённому на keys. Перестроений в этих сериях нет.

Генератор случайных ключей C++ отличается от math/rand Go. Поэтому случайные
строки двух языков относятся к разным наборам. Набор искусственных коллизий
совпадает, и контрольные числа проб для него совпадают в обеих реализациях.
